# Memory — SoW Reviews & Assessments

This folder stores SoW documents and review assessments locally.
Contents are gitignored to keep sensitive customer data out of version control.

## Usage

When reviewing a SoW, the agent saves:
- The source SoW document (PDF, text)
- The AWS Calculator export
- The generated review assessment
- Any follow-up notes or revisions

## File naming convention

```
memory/
├── 2026-07-13_customer-name_sow.pdf
├── 2026-07-13_customer-name_calculator.json
├── 2026-07-13_customer-name_review.md
└── ...
```
