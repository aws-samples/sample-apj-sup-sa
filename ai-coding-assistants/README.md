# AI coding assistants

Samples and reusable assets for AI-assisted development with Claude Code, Codex,
and Kiro — proxies, gateways, agentic coding demos, Kiro Powers, and shareable
Agent Skills.

## Agent Skills

Reusable skills that work across Claude Code, Codex, and Kiro live under
`skills/`. They are also distributed through this repo's Claude Code plugin
marketplace:

```
/plugin marketplace add aws-samples/sample-apj-sup-sa
/plugin install aws-bento-deck@apj-sup-sa
```

| Skill | Description |
|-------|-------------|
| [`aws-bento-deck`](skills/aws-bento-deck/README.md) | Build AWS-branded BENTO presentations (self-contained `.bento.html`) from a plan file. |
