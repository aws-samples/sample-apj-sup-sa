# Performance Budget Extension

## Opt-In Prompt

Would you like to enable **Performance Budget** enforcement?

This extension adds:
- Bundle size budget checks (fail if total exceeds threshold)
- Individual package size limits
- Import cost analysis (per-import byte cost)
- Tree-shaking effectiveness scoring
- Duplicate package detection with size impact

**Recommended for**: Frontend/browser applications, SPAs, performance-critical web apps.

**Additional time**: ~3-5 minutes per analysis.
