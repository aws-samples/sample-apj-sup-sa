# Supply Chain Security Extension

## Opt-In Prompt

Would you like to enable **Supply Chain Security** analysis?

This extension adds:
- Typosquatting detection (package names similar to popular packages)
- Maintainer trust assessment (new maintainers, compromised accounts)
- Install script analysis (pre/post-install hooks running arbitrary code)
- Provenance verification (SLSA, Sigstore attestations)
- Dependency confusion checks (internal vs public registry conflicts)

**Recommended for**: Production applications, enterprise environments, regulated industries.

**Additional time**: ~5-10 minutes per analysis.
