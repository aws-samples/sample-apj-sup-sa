Amazon Bedrock service-tier benchmark

How to read this report

Each row compares one tier against the default (Standard) tier in the same context: same model, endpoint, API, inference scope, region, prompt size and cache mode. Δ is the tier's median (p50) minus default's median. Green = faster, red = slower, grey = not significant (the 95% bootstrap confidence interval includes zero).

TTFT time to first token (including reasoning) · TTFAT time to first answer token · E2E end-to-end latency · ITL inter-token latency ((E2E−TTFT)/(output tokens−1)). Burst = share of samples whose stream arrived all at once after queueing (decode under 5% of E2E); for those, TTFT is close to E2E and ITL does not measure decode speed. Cold samples that read from cache, warm samples that missed the cache, and samples served on a different tier are excluded and counted.
