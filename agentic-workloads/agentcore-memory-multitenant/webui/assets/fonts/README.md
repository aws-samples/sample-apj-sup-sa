Usage terms: the Amazon Ember licensing guidelines, also bundled with
[`aws-diagram-design`](../../../../../ai-coding-assistants/agent-plugins/aws-diagram-design/skills/aws-diagram-design/assets/fonts/Amazon-Ember-Licensing-Guidelines.pdf)
