        01 · AuthN

        The Runtime and then the Gateway each verify the Cognito JWT’s signature, issuer and client before any code runs.

        02 · Context

        The interceptor maps the JWT’s client_id to a brand and agent from a fixed table, and drops any tenant_id / namespace / actor_id the caller sent.

        03 · IAM

        The tools Lambda assumes that brand’s own role. It only allows Memory namespaces under /tenant/<brand>/* and the policies-<brand> vector index, so even a code bug cannot cross brands.

        Observability: X-Ray traces for the Lambdas and the Runtime agent (GenAI spans per model call), CloudWatch GenAI Observability, and one CloudWatch dashboard for Runtime, Gateway, Lambda and Bedrock metrics.

        Every reply’s “What happened” trace shows exactly which client, namespaces, actorId and role were used. Detail: README.md and EVIDENCE.md in the repo.
