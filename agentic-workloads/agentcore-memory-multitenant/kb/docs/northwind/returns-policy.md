# Northwind Apparel Co. returns policy

## Return window
Northwind Apparel Co. accepts returns within 30 days of delivery. Items must be unworn, unwashed and have their original tags attached.

## Return shipping
Returns are free for orders over $75: we email a prepaid return label. For orders of $75 or less, a $6.95 return shipping fee is deducted from the refund.

## Refund timing
Refunds go back to the original payment method within 5-7 business days after the returned item reaches our warehouse.

## Final sale
Items marked "Final Sale", gift cards and underwear cannot be returned or exchanged.
