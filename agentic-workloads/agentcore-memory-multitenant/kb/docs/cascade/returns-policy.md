# Cascade Mart returns policy

## Return window
Cascade Mart accepts returns within 14 days of purchase with the original receipt or order number.

## Electronics
Opened electronics can only be refunded as store credit, and a 15% restocking fee applies. Unopened electronics follow the normal 14-day window.

## Refund method
Refunds for in-store purchases are given in the original payment method at the till; online orders are refunded within 7-10 business days.
