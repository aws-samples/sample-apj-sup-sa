# Borealis Outfitters sizing guide

## Jackets
Borealis jackets have an athletic cut and run small. If you plan to layer a fleece or down mid-layer underneath, order one size up.

## Jacket chest measurements
S fits 36-38 in, M fits 39-41 in, L fits 42-44 in, XL fits 45-47 in.

## Boots
Borealis hiking boots run narrow: order half a size up from your usual shoe size, especially for thick hiking socks.
