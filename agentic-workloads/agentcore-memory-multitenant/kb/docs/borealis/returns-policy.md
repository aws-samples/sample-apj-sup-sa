# Borealis Outfitters returns policy

## Return window
Borealis Outfitters accepts returns within 60 days of delivery under our Trail Promise: gear you have tried outdoors once can still be returned if it did not work for you.

## Return shipping
Returns are always free at Borealis Outfitters, whatever the order value. Start a return online to get a prepaid label.

## Exchanges
Exchanges for a different size are shipped as soon as the return is scanned by the carrier, before it reaches our warehouse.

## Refund timing
Refunds go back to the original payment method within 3-5 business days after we receive the return.
