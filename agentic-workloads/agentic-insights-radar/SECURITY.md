# Reporting security issues

If you discover a potential security issue in this project, notify AWS/Amazon Security via the
[vulnerability reporting page](https://aws.amazon.com/security/vulnerability-reporting/) or
directly via email to [aws-security@amazon.com](mailto:aws-security@amazon.com).

Please do **not** create a public GitHub issue for security problems.

This is sample code, for non-production usage. See [docs/security/threat-model.md](docs/security/threat-model.md)
and [docs/security/security-matrix.md](docs/security/security-matrix.md) for the threat model and the controls
the sample includes.
