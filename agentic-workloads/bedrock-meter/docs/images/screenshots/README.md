# Console Screenshots

Bedrock Meter console images used in the README and operational documentation.

- `console-overview.png`: Overall usage, trends, and recent activity
- `console-users.png`: Per-user daily/weekly/monthly quotas
- `console-user-detail.png`: Details for `choichul`, token breakdown, and operational actions
- `console-user-detail-prorhap.png`: Top viewport of the `prorhap` detail page
- `console-user-hourly-prorhap.png`: Details for `prorhap` with hourly token trends over the last 24 hours
- `console-statistics.png`: Athena-based model analytics
- `console-limit-editor.png`: Per-user limit and exemption editor
- `console-audit.png`: Operational changes and system decisions
- `archive/`: Earlier screens and alternate captures from development and verification

Use only final screenshots that match actual behavior in published documentation. When screens or
policy wording change, replace representative images using the same filenames. Keep earlier images
in `archive/` only when needed.

See the [project README](../../../README.md) for installation and the documentation index.
