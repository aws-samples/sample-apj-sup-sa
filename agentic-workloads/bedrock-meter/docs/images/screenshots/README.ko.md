# 콘솔 스크린샷

README와 운영 문서에서 사용하는 Bedrock Meter 콘솔 이미지입니다.

- `console-overview.png`: 전체 usage, trend, recent activity
- `console-users.png`: 사용자별 day/week/month quota
- `console-user-detail.png`: `choichul` 상세, token breakdown, 운영 작업
- `console-user-detail-prorhap.png`: `prorhap` 상세 화면의 최상단 viewport
- `console-user-hourly-prorhap.png`: `prorhap` 상세, 최근 24시간 hourly token 추세
- `console-statistics.png`: Athena 기반 모델별 분석
- `console-limit-editor.png`: 사용자별 limit와 exempt 편집
- `console-audit.png`: 운영 변경과 시스템 판단 이력
- `archive/`: 개발·검증 과정의 이전 화면과 대체 캡처

문서에 노출하는 이미지는 실제 동작과 맞는 최종 화면만 사용합니다. 화면이나 정책 문구가 변경되면
대표 이미지를 같은 이름으로 교체하고, 이전 이미지는 필요할 때만 `archive/`에 보관합니다.

설치 방법과 전체 문서 목록은 [프로젝트 README](../../../README.ko.md)를 참고하세요.
