## Welcome to Part 1

Before you design anything, run the finished product. You will open the baseline
agent - already in your workspace, nothing to clone - run it locally, deploy it to
a managed AgentCore Runtime, and invoke it against a live anomaly so you can see
what "done" looks like. This grounds the canvas decisions you make in Part 2.
